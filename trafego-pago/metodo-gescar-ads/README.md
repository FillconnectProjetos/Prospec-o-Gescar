# Método Gescar ADS

Cada passo manual do piloto é candidato a recurso do produto.

| Passo do piloto | Vira no Gescar ADS | Módulo |
| --- | --- | --- |
| Teto de custo por cliente a partir de ticket, permanência e margem | Calculadora de teto de CPL e custo por demo | Radar |
| Ciclos com critério de "deu resultado" | Orçamento escalonado com recomendação e aprovação humana | Copiloto |
| Código de origem na mensagem do WhatsApp | Atribuição de lead por anúncio sem CRM complexo | Radar |
| Regras de corte | Alertas com ação sugerida | Radar e Copiloto |
| Log de decisões | Histórico de ações aprovadas e resultado | Copiloto |
| Antes e depois com foto real | Peça gerada do estoque | Estúdio |
| Eventos de funil ao Meta | Lead, Qualificado, Test Drive, Proposta e Venda via Conversions API | Integração Meta |
