# 01 · Modelos de campanha para revenda

O agente monta campanhas a partir destes cinco modelos. Se o pedido do lojista não couber em nenhum, o agente pergunta mais antes de criar algo diferente.

## Regras comuns a todos os modelos

- **Objetivo da campanha:** Cadastros (Leads). É o objetivo da Meta para captar clientes e o único com formulário instantâneo (doc 02 da biblioteca).
- **Local de conversão:** formulário instantâneo no piloto (medição mais confiável, ver arquivo 05). WhatsApp quando o lojista preferir, com mensagem pré-preenchida contendo o código do veículo.
- **Estrutura:** 1 campanha, 1 conjunto de anúncios, 2 a 3 anúncios (variações de criativo). Mais que isso divide verba pequena demais.
- **Advantage+ leads:** só depois que a medição da loja estiver validada (doc 02 da biblioteca).
- **Tudo nasce pausado.** O lojista aprova a ativação.
- **Nome:** `LOJA | Modelo | Veículo ou tema | Região | AAAA-MM-DD`. Exemplo: `AUTOCENTER | CarroDoDia | Corolla 2020 | Cuiabá 40km | 2026-12-02`.
- **Veículo vendido = anúncio pausado.** Quando o estoque do Gescar marcar o carro como vendido, o anúncio dele é pausado na mesma hora (regra automática a incluir no motor de regras).

## Modelo 1 · Carro do dia

| | |
| --- | --- |
| Quando usar | Destacar um veículo com bom preço, alta procura ou que o lojista quer girar rápido |
| Veículos | 1 |
| Criativo | 3 a 5 fotos reais do Estúdio (frente, lateral, interior, painel com km) ou vídeo curto |
| Duração | 3 a 7 dias |
| Verba inicial | R$ 20 a R$ 30 por dia **[HIPÓTESE]** |
| Sucesso | Leads dentro do teto de CPL da loja e pelo menos 1 test drive na semana |
| Encerrar quando | Carro vendido, 7 dias sem test drive, ou CPL acima de 2 × o teto |

## Modelo 2 · Estoque da semana

| | |
| --- | --- |
| Quando usar | Mostrar variedade, manter a loja presente o tempo todo |
| Veículos | 5 a 10, de faixa de preço parecida (não misturar popular com premium) |
| Criativo | Carrossel, um card por veículo, com ano, km e preço ou "consulte" |
| Duração | 7 dias, renovando os veículos toda semana |
| Verba inicial | R$ 30 a R$ 50 por dia **[HIPÓTESE]** |
| Sucesso | Custo por lead dentro do teto e leads distribuídos entre vários veículos |
| Encerrar quando | Fim da semana; trocar vendidos e repetir |

## Modelo 3 · Giro de estoque

| | |
| --- | --- |
| Quando usar | Veículo parado há mais de 45 dias **[HIPÓTESE: o prazo ideal muda por loja]** |
| Veículos | 1 a 3 |
| Criativo | Fotos reais + condição especial **verdadeira** (preço revisado, revisão feita, garantia). Sem condição real, não rodar este modelo |
| Duração | 7 dias |
| Verba inicial | R$ 20 a R$ 30 por dia por veículo **[HIPÓTESE]** |
| Sucesso | Pelo menos 1 visita ou test drive do veículo |
| Encerrar quando | Vendido, ou 14 dias sem test drive (aí o problema é preço, não anúncio, e o agente diz isso ao lojista) |

## Modelo 4 · Avaliação do usado (troca)

| | |
| --- | --- |
| Quando usar | Captar quem quer trocar de carro. Gera lead de compra e abastece o estoque |
| Veículos | Nenhum específico; a peça mostra a loja e o pátio |
| Criativo | "Avaliamos seu carro na troca" + fotos reais da loja. Formulário pede marca, modelo e ano do carro atual |
| Duração | Contínuo, revisado toda semana |
| Verba inicial | R$ 20 a R$ 30 por dia **[HIPÓTESE]** |
| Sucesso | Avaliações agendadas |
| Encerrar quando | O lojista não dá conta de atender as avaliações |

## Modelo 5 · Feirão ou data sazonal

| | |
| --- | --- |
| Quando usar | Ação com data marcada (feirão, Black Friday, fim de ano). Ver arquivo 08 |
| Veículos | Seleção do lojista |
| Criativo | Data e local claros, condições reais, carrossel dos veículos participantes |
| Duração | 5 a 10 dias antes da data, encerrando no último dia |
| Verba inicial | Definida com o lojista, dentro do teto mensal |
| Sucesso | Agendamentos e visitas no período |
| Encerrar quando | Fim da ação. A campanha já é criada com data de término |

## Como o agente escolhe

| Pedido do lojista | Modelo |
| --- | --- |
| "Quero vender o carro X" | 1 · Carro do dia |
| "Quero aparecer mais" / "anuncia a loja" | 2 · Estoque da semana |
| "Esse carro não sai" / carro parado | 3 · Giro de estoque (se houver condição real) |
| "Preciso de carro para o estoque" / "quero pegar troca" | 4 · Avaliação do usado |
| "Vou fazer um feirão" / data especial | 5 · Feirão |
